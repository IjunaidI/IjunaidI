### Built

| | | |
|---|---|---|
| **[WheelBuilds](https://github.com/IjunaidI/WheelBuilds)** | Wheel and tire storefront that knows what fits. Enter your car, see only parts that physically bolt on. | `MedusaJS` `Next.js 15` `PostgreSQL` `Meilisearch` |
